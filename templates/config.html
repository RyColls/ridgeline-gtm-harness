How a weight changes

  1. RevOps edits a copy of the JSON as v1.4 (a pull request, so it's reviewed and logged).
  2. v1.4 runs in shadow mode on live leads; this page and every trace show the v1.3 → v1.4 diff.
  3. Promote only if Tier A precision holds ≥ 70% on rep feedback. Rollback = point back to v1.3.
